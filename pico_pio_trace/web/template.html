Manual FIFO events

Add one or more 32-bit words at a precise cycle. TX entries model host StateMachine.put() operations. RX injection is a debugger-only facility for preloading or testing RX-side behavior.

Selected cycle · TX __INITIAL_TX_LEVEL__ / __TX_CAPACITY__ · RX __INITIAL_RX_LEVEL__ / __RX_CAPACITY__
Hexadecimal, binary, octal, decimal, signs, and underscores are accepted; separate multiple words with commas, semicolons, or whitespace. Events are applied in written order before the PIO instruction at that cycle. The summary and debugger expose cycle-start, post-host-event, and end-of-cycle FIFO states, so a TX word remains visible even when PULL consumes it immediately. TX writes block when full. Debug RX injection appends while space exists and reports/drops extra words when RX is full.

Manual IRQ events

Schedule a host/other-state-machine change to any PIO IRQ flag. The change is applied before the selected function executes its instruction at that cycle.

Selected cycle · 0b00000000
WAIT 1 IRQ consumes and clears a matching flag when the condition is met. irq(block, n) sets the flag and remains stalled until a scheduled clear event releases it.
GPIO tip: one click creates a persistent transition. Create a pulse with two clicks—for example, set GPIO15 to 1 at cycle 100 and back to 0 at cycle 200. Event changes are applied before the PIO instruction in that cycle.
